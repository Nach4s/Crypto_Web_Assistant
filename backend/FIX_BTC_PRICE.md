# 🔧 Исправление: Цены в BTC вместо USD

## 🐛 Проблема

AI возвращал цены в BTC вместо USD:
```
"На данный момент цена Firo (FIRO) составляет 0.000022023991351141513 BTC"
```

## 🔍 Причина

Система получала данные из двух источников:
1. **Полные данные** (`crypto` раздел) - цены в USD ✅
2. **Трендовые монеты** (`trending` раздел) - цены только в BTC ❌

AI использовал данные из `trending`, потому что не было явного указания приоритизировать USD.

## ✅ Решение

### 1. Обновлён системный промпт AI

Добавлены чёткие инструкции:
```python
- ВСЕГДА используй цены в USD (долларах), НЕ в BTC
- Если есть раздел "crypto" или "stocks" с полными данными - используй ИХ в первую очередь
- Раздел "trending" содержит только цены в BTC - используй его ТОЛЬКО если нет данных в "crypto"
```

### 2. Добавлены новые монеты в словарь

```python
crypto_keywords = {
    # ... существующие ...
    'firo': 'zcoin', 'firo coin': 'zcoin',
    'worldcoin': 'worldcoin-wld', 'wld': 'worldcoin-wld',
}
```

## 🎯 Как работает приоритизация

```
Запрос пользователя: "Цена FIRO"
    ↓
Система извлекает: crypto_ids = ["zcoin"]
    ↓
Получает данные:
  - crypto["zcoin"] = {price: $1.85, change_24h: +2.5%} ✅
  - trending[...] = {price_btc: 0.000022} ❌
    ↓
AI видит инструкцию: "Используй crypto в первую очередь"
    ↓
Ответ: "Цена Firo: $1.85 USD (+2.5%)" ✅
```

## 💡 Почему это важно

### Проблемы с ценами в BTC:
- ❌ Неудобно для пользователей (нужно конвертировать)
- ❌ Сложно сравнивать с акциями
- ❌ Не показывает реальную стоимость
- ❌ Нет изменений за 24ч в фиате

### Преимущества цен в USD:
- ✅ Понятно сразу
- ✅ Легко сравнивать
- ✅ Показывает реальную стоимость
- ✅ Есть изменения за 24ч
